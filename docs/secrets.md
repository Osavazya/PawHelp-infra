# Secrets

Create these as GitHub repository or organization secrets. Do not commit real values.

## AWS

- AWS_ACCESS_KEY_ID
- AWS_SECRET_ACCESS_KEY
- AWS_REGION
- TF_STATE_BUCKET

## Container registry

- GHCR_USERNAME
- GHCR_TOKEN

## Backend runtime

- SECRET_KEY
- DATABASE_URL
- POSTGRES_PASSWORD
- GOOGLE_MAPS_API_KEY
- LIBRETRANSLATE_API_KEY

## TeamCity

- TEAMCITY_ADMIN_PASSWORD
- TEAMCITY_GHCR_TOKEN

## Argo CD

- ARGOCD_ADMIN_PASSWORD
- ARGOCD_REPO_TOKEN
